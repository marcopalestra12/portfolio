# My Portfolio

This is a simple personal portfolio website built with HTML, CSS, and a little JavaScript.

## Run locally

Open `index.html` in a browser.

## Customize

- Update the name, bio, and contact details in `index.html`
- Change colors and layout in `style.css`
- Replace the sample project cards with your own work

## Live demo

You can view the site by opening the HTML file locally or by deploying it to GitHub Pages.
